# 项目概述

<figure><img src=".gitbook/assets/chain (1).png" alt=""><figcaption></figcaption></figure>

PulsWeb2 是基于三层架构构建的机密计算平台，用于承载对运行时机密性与可核验性有要求的工作负载。

## 三层架构

1.  **第一层：主链层 (用户逻辑与结算)**
    基于 Polkadot 构建（未来将接入更多网络），负责处理用户所有的业务逻辑、全局治理、资产结算和任务调度。
2.  **第二层：侧链层 (密钥管理与共识)**
    由 `tee-dsecret` 驱动，使用 CometBFT 共识。该层实现 **分布式密钥生成 (DKG)** 与 **代理重加密 (PRE)** 等密钥协作机制，用于降低单点持有完整秘密的风险。
3.  **第三层：计算层 (Worker 与执行)**
    执行层，`tee-worker` 作为 Kubernetes 控制器运行在受支持的 TEE 硬件上。该层可通过 EGO/LibOS 等方式承载容器化工作负载，具体兼容性与约束以实现为准。

## 核心产品

*   **机密服务 (Confidential Service):** 具有 K8s 特性（部署、存储卷、网络）的长期运行机密容器。
*   **机密任务 (Confidential Task):** 具有可验证执行结果的短期批处理任务。
*   **GPU 计算服务:** 由 NVIDIA/Intel TEE 保护的高性能 AI 和计算负载。
*   **机密存储:** 为敏感应用数据提供静态加密存储。

## 核心特性

*   **可核验执行**：通过证明材料与审计记录支持第三方核验（支持范围以当前实现为准）。
*   **容器化交付**：面向 Docker 镜像提供部署与运行流程（兼容性与修改需求以实现为准）。
*   **治理机制**：可在特定环境中启用治理模块（是否开放以环境配置为准）。
