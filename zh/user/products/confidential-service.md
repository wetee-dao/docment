# 部署机密应用 (Confidential Service)

**机密应用**（Service）适用于需要长时间在线运行的程序，比如 Web 网站、数据库或 API 服务。

### 安全边界与核验
机密应用工作负载在 TEE 边界内运行。部署与访问控制应以远程证明（Attestation）与审计记录为依据，并以当前产品实现支持的证明材料为准。

### 如何部署？（3 步）

#### 第一步：准备镜像
PulsWeb2 支持标准的 Docker 镜像。将镜像上传到公共仓库（如 Docker Hub）或私有仓库即可。

#### 第二步：填写配置
1.  登录 PulsWeb2 dApp。
2.  进入 **“Confidential Service”** 页面，点击 **“Create”**。
3.  **填写信息**：
    *   **Image**: 输入你的 Docker 镜像地址（例如 `nginx:latest`）。
    *   **Resources**: 选择你需要的 CPU 和内存大小。
    *   **Port**: 填写程序对外提供的端口。

#### 第三步：启动
点击 **“Deploy”** 按钮并签名。系统根据调度策略为工作负载匹配可用节点并启动实例；启动耗时与资源供给、镜像拉取等因素相关。

### 监控与管理
*   **实时日志**：可在控制台查看工作负载运行输出。
*   **状态核验**：可在控制台查看与该工作负载关联的证明材料（如 Attestation 摘要/引用），并据此核验运行环境与工作负载标识。
*   **伸缩与停止**：可调整资源或停止服务；计费与结算规则以当前产品实现为准。

---

**适用场景**：需要长期在线、且对运行时机密性与可核验性有要求的服务型工作负载。
