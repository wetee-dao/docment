# 机密存储

机密存储用于为机密工作负载提供持久化数据能力，并在存储侧引入加密与访问控制边界（具体能力以当前产品实现为准）。

### 它是如何工作的？
机密存储在数据写入持久化介质前完成加密，并将密钥材料与工作负载身份/证明关联，以降低明文暴露面。

*   **密钥边界**：密钥材料由机密边界承载，导出与访问策略以实现为准。
*   **访问绑定**：可将存储访问权限与指定工作负载/命名空间等策略绑定（以控制面支持能力为准）。

### 功能亮点
1.  **持久化保存**：即使你的机密服务重启，数据依然保持加密且可读取。
2.  **冗余与可用性**：数据的冗余策略与可靠性以底层存储实现与部署策略为准。
3.  **最小暴露面**：存储节点仅可见密文与元数据的可见范围取决于实现；隐私边界以当前产品实现为准。

### 使用方法
在部署应用时，挂载一个卷（Volume）并勾选 **“Confidential Encryption”** 即可。
