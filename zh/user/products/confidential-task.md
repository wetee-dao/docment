# 运行机密任务 (Confidential Task)

**机密任务**（Task）适用于一次性或批处理计算场景，例如数据分析、模型训练或密钥生成。

### 什么是机密任务？
与机密服务不同，机密任务在完成计算后会自动关闭并释放资源。它最适合处理那些对隐私要求极高、且不需要持续运行的任务。

### 使用流程

1.  **提交任务**：在控制台进入 **“Confidential Task”**。
2.  **设置触发条件**：可设置任务为“立即运行”或“定时运行”（以控制面能力为准）。
3.  **计算与结果交付**：任务运行过程中中间数据在 TEE 边界内处理；结果的加密与投递方式以当前产品实现支持能力为准。
4.  **自动结算**：任务结束的瞬间，计费立即停止。

### 为什么选择机密任务？
*   **资源释放**：任务完成后释放资源，避免长期占用。
*   **成本模型**：按任务运行时长计费；计费口径以当前规则为准。
*   **并发能力**：可并发提交任务；上限由配额、资源供给与调度策略决定。

---

**适用场景**：医学图像分析、多方安全计算（MPC）、大规模数据脱敏处理等对运行时机密性有要求的批处理任务。
