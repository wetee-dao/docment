# 参与 DAO 治理

PulsWeb2 可在特定部署环境中启用治理功能，用于平台参数、资源与资金相关事项的社区协作决策。治理是否开放与可参与范围以当前环境配置为准。

### 为什么要参与？
*   **参数与路线决策**：对支持设备、资源策略等事项进行表决（范围以当前治理模块与提案类型为准）。
*   **资金使用审议**：对国库资金的拨付与用途进行审议与表决（若当前环境启用国库模块）。
*   **需求协同**：通过提案与投票机制集中反馈并形成可执行决议。

### 核心角色
1.  **参与者**：在当前环境具备治理权限的用户可参与讨论与投票。
2.  **委员会 (Council)**：由社区选出的代表，负责处理一些紧急事务或快速提案。
3.  **技术委员会**：负责审查代码，确保技术升级的安全性。

### 如何参与？
1.  **开通治理权限**：确认你的账号在当前环境已开通治理相关能力。
2.  **进入治理页面**：在 dApp 中点击 **“Governance”**。
3.  **查看活跃提案**：看看大家正在讨论什么，点击进去阅读详情。
4.  **投票**：根据提案规则选择“赞成”、“反对”或“弃权”。

---

治理相关的角色、权限、提案类型与执行方式以当前链端实现为准。
