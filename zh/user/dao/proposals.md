# 如何发起提案

提案用于将改进建议、参数调整或资金拨付等事项进入链上治理流程。可发起的提案类型、押金要求与投票规则以当前环境的治理模块配置为准。

### 发起提案的步骤

#### 第一步：讨论 (Pre-discussion)
在正式提交前，建议在社区渠道（如 Discord 或治理论坛）进行公开讨论，收集反馈并明确需求、影响范围与执行方式。

#### 第二步：提交提案 (Submission)
1.  进入 **“Governance” -> “Proposals”**。
2.  点击 **“Create Proposal”**。
3.  **填写详情**：
    *   **标题与描述**：清晰地说明你的想法、目的以及需要的资金支持（如果有）。
    *   **执行逻辑**：如果是技术参数修改，需要填写对应的链上命令。
4.  **缴纳押金**：若当前治理模块要求押金/质押，需按规则提交；退还条件以链端实现为准。

#### 第三步：投票期 (Voting)
在投票期内，具备权限的账户可按规则投票。提案链接可用于信息同步与讨论。

#### 第四步：执行
如果投票通过，系统的“执行器”会自动运行相关的代码，或者由委员会按照提案内容进行资金拨付。

---

建议在提案中包含明确的目标、影响范围、成本估算与执行计划，便于审议与落地。
